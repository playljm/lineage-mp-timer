> **자동 모드의 어떤 OCR 결과가 부정확했길래 사용자가 수동으로 바꿨는가?**

- (a) ADENA template matching이 잘못된 숫자 출력

→ **Phase 1에서 사용자 추가 진단 필요**.

## 11. Phase 3c — Phase 3a 회귀 fix (2026-05-07T11-46-28)

### 발견된 회귀
- Phase 3a fix가 `validateROIs`에서 ADENA width<50 issue 추가 → `valid=false`
- `ensureAutoModeROIs` 검증에서 valid=false → cachedROIs 안 만들어짐
- MP/EXP/LEVEL OCR도 자동 모드에서 호출 안 됨
- 매초 같은 메시지 도배 → hybridLog 20슬롯 모두 ADENA 실패로 채워짐

### 수정
**`roi-detector.js` validateROIs**:
- ADENA 단독 issue를 `adenaOnlyIssues` 배열로 분리
- `valid`는 ADENA 외 issues로만 결정
- 반환값에 `adenaIssues` 별도 추가

**`app.js` ensureAutoModeROIs**:
- 필수 ROI 체크에서 ADENA 제거 (mp/exp/level만 필수)
- ADENA width<50이면 30초 throttled 안내 + `textROIs.adena = null` 설정
- `autoDetect.adenaRegion` 갱신은 textROIs.adena 존재 시만
- 자동 ROI 탐지 실패 메시지 30초 throttle

### 효과
- 자동 모드에서 ADENA 폭 부족이어도 MP/EXP/LEVEL OCR 정상 호출

**원인 trace**:

- adenaIcon 자동 detect: `(1212, 849) 45×40` ← gameRegion 우측 끝(1272)에서 15px만 떨어짐
- ADENA textROI: `x = iconX + iconWidth + 3 = 1260`, `width = max(90, 45×2.5) = 113`
- **textROI x_end = 1373 → gameRegion frameW(1272) 초과 101px**
- 절대좌표 변환 후 캡처: x=2541, w=113 → 모니터 우측이 게임창 우측 가장자리와 동일 → **101px 모니터 밖 검정**

**v1.4.0 b20407a 가정 깨짐**:
- 가정: "captureStream이 모니터 전체를 캡처하므로 gameRegion 외부도 캡처 가능"
- 사용자 환경: 게임창이 듀얼 모니터의 우측 가장자리와 일치 → 모니터 자체가 더 우측에 픽셀이 없음 → 캡처 영역이 검정

### MP 인식 실패 — 사용자 anchor 입력값 문제

**hybridLog**:
```
MP ❌ paddle cur 자릿수 over (cur=19972 >> userMax=197): paddle 폐기
```

- 이미지 mp.png: "MP : 199/242" 또렷
- 사용자 anchor: `mpMax = "197"` ← 잘못됨 (실제 화면 max=242)
- paddle이 "199/242" 또는 "19972"로 읽음 → cur 자릿수가 userMax(197)를 자릿수 over → 폐기
- 사용자가 anchor mpMax를 정정하면 (197 → 242) 자동 해결될 가능성 높음

### LEVEL — anchor 정정 필요
- OCR "29" 정확히 읽음
- 사용자 anchor `levelStart="7"`, `levelNow="7"` ← 실제 캐릭 레벨 29
