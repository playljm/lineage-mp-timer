## 🔬 Root Cause 분석

### 1. EXP/LEVEL ROI 겹침 (CRITICAL)

**진단 좌표**:
```
textROIs.level = { x: 3,  y:723, w:83, h:17 }  →  [3 ~ 86]
textROIs.exp   = { x:23,  y:723, w:63, h:17 }  →  [23 ~ 86]
```
같은 끝점, 시작점만 20px 차이 — 두 ROI가 거의 동일 영역.

**버그 위치** (`roi-detector.js:524~528`):
```js
let expStart_x = -1;
for (const c of sorted) {
  if (c.xStart > lvlEnd + 10) { expStart_x = c.xStart; break; }
}
if (expStart_x < 0) expStart_x = rightMost.xStart;  // 🚨 LEVEL과 같은 cluster!
```

**시나리오**:
1. `findLevelTextLines` 가 좌측 미니 패널에서 cluster 2+개 검출
2. 모든 cluster 가 25px 이내 인접 → `lvlEnd` 가 마지막 cluster 까지 통합 (line 519~522)
3. `expStart_x` 검색 (line 524~527): `lvlEnd + 10` 보다 우측에 cluster 없음 → `-1`
4. **버그 폴백**: `expStart_x = rightMost.xStart` — `rightMost`는 이미 LEVEL에 통합된 마지막 cluster
5. 결과: EXP ROI 가 LEVEL ROI 안 좌표를 가리킴

**왜 EXP=0% 상황에서 발생하나**: 진짜 EXP% 텍스트가 0% 가까이 비어있어서 우측 EXP cluster 비검출. 좌측 한글 시스템 텍스트(예: 캐릭터명, 퀘스트 알림)의 글자별 cluster만 잡혀 LEVEL 영역으로 통합 → EXP 폴백이 그 안 좌표.

### 2. LEVEL OCR 결과 한글 → anchor 굳음

LEVEL OCR이 `Lv.12` 라고 보고하지만 이미지는 한글 시스템 텍스트. 즉 paddle/tess가 한글에서 우연히 "12" 비슷한 패턴을 추출했거나 anchor stale. 1~99 정수 sanity 부재.

### 3. EXP anchor=0 stale (간접)

```
"anchors.expStart": "0.0000",
"anchors.expNow":   "0.0000"
```
anchorEXP=0 상태에서 (line 4580):
```js
if (anchorBoth > 0) { /* 점프 검증 */ }
// else: 첫 OCR 결과 그대로 통과
```
ROI 버그로 정상 EXP 값이 한 번도 안 잡혔으므로 anchor 영원 0. ROI fix 후엔 정상 흐름이지만, **anchor=0 시 첫 misread 굳음 위험**이 있어 5회 일관 검증 추가.

## 🎯 작업 범위 (v1.5.9)

### CRITICAL-1 — EXP cluster 미발견 시 LEVEL과 분리 (`roi-detector.js`)

```js
// [v1.5.9] EXP cluster 가 LEVEL 과 충분히 떨어져 있어야 정상 layout.
//   진단 2026-05-08T14-41-55: 좌측 한글 텍스트 cluster들이 모두 인접해 lvlEnd로 통합
//   → expStart_x 검색 실패 → 폴백 rightMost.xStart 가 LEVEL 안 가리킴 → 동일 영역.
//   해결: expStart_x 미발견 시 EXP ROI null (해당 사이클 EXP 갱신 skip).
let expStart_x = -1;
for (const c of sorted) {
  if (c.xStart > lvlEnd + 20) {  // gap 10→20 (cluster 분리 보수화)
    expStart_x = c.xStart;
    break;
  }
}
rois.level = {
  x: Math.max(0, leftMost.xStart - PAD_X),
  y: y,
  width: (lvlEnd - leftMost.xStart) + PAD_X * 2,
  height: h
};
if (expStart_x >= 0) {
  rois.exp = {
    x: Math.max(0, expStart_x - PAD_X),
    y: y,
    width: (rightMost.xEnd - expStart_x) + PAD_X * 2,
    height: h
  };
} else {
  // EXP cluster 분리 실패 — null 반환 (호출부에서 막대 fallback 또는 region 갱신 skip)
  rois.exp = null;
}
```

**호출부 처리** (`app.js:4960` 영역 — adena와 유사):
- `textROIs.exp === null` 이면 `autoDetect.expRegion` 갱신 skip + 30s throttle 안내.

### CRITICAL-2 — LEVEL OCR 1~99 sanity (`app.js`)

LEVEL paddle/tess 결과가 1~99 정수가 아니거나 anchor 와 너무 차이나면 폐기:
- `level < 1 || level > 99` → 폐기
- `Math.abs(level - anchor) > 5` 시 v1.5.5 D fix 의 `paddle 일치 + 3회 일관` 강화 (이미 존재 — 유지/확인)

LEVEL anchor 가 한글 OCR 결과로 굳지 않도록:
- anchor 갱신 전 새로운 sanity 게이트.

### HIGH-1 — EXP anchorEXP=0 stale 보호 (`app.js`)

// [v1.5.9] anchorEXP=0 stale 시 첫 OCR misread 굳음 위험 차단.
