# Lineage MP Timer

리니지 클래식 플레이어를 위한 MP 자연회복 완충 시간 계산·알림 Electron 앱.

MP가 차는 동안 다른 업무를 보다가 완충되면 토스트 + 사운드로 알려줍니다.

## 공식

- 기본 틱 주기: 16초 (정지) / 32초 (이동) / 64초 (전투)
- WIS 기본 회복량: 14↓=1, 15-16=2, 17-18=3, 이후 WIS 2당 +1
- 파란물약 추가: `max(1, WIS - 10)` MP/틱 (지속 600초, 자동 갱신 가정)
- 메디테이션: +5 MP/틱 (지속 640초, 정지 상태만)
- 여관/아가타: +2 MP/틱, 싱잉/히든밸리: +3 MP/틱
- 수정 지팡이: +10 MP/틱

## 실행

```bash
npm install
npm start        # 개발 실행
npm run dev      # --dev 플래그 포함 실행
npm run build    # Windows NSIS 설치 파일 + 포터블 빌드
npm test         # 엔진 유닛 테스트
```

## 단축키

| 키 | 동작 |
|---|---|
| `Space` | 타이머 시작/일시정지 |
| `R` | 리셋 |
| `F1` | 항상 위 토글 |
| `F2` | 트레이로 숨기기 |

## 지원 범위

- 주 대상 직업: 마법사 / 요정 (메디테이션 사용 가정)
- 버프 지속시간 만료 시 자동 갱신 가정 (충분한 파란물약 보유 전제)
- 다른 직업은 메디테이션 체크 해제로 사용 가능

## 레퍼런스

- 리니지 파워북 MP 회복(틱)
- 리니지 리마스터 인벤 메디테이션 DB
- 리클인포 파란물약
